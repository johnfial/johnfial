# Practice code

Practice code, split out of my [profile repo](https://github.com/johnfial/johnfial) so that page can be just a README. Most of this is from 2021 through early 2023: PDX Code Guild bootcamp labs and the exercises I wrote as a teaching assistant there, Cracking the Coding Interview and structy drills, Advent of Code, and a lot of Django, Flask, and JavaScript play.

It's practice. Expect rough edges, half-finished ideas, and commit messages like "practice ~15".

| Folder | What's in it |
|---|---|
| `general/` | Data structures and algorithms: Cracking the Coding Interview chapter by chapter, plus LeetCode, Codewars, CodeSignal, and Learn Python exercises |
| `interview_practice/` | Timed interview questions, Pramp and InterviewBit problems, and questions to ask an interviewer |
| `teaching_assistant/` | Lab originals and the new labs I wrote while a TA at PDX Code Guild (2021) |
| `play_python_lab_edits/` | My reworked versions of bootcamp Python labs: ATM, tic-tac-toe, blackjack advice, Roman numerals, and friends |
| `play_django/` | Django labs: grocery list, URL shortener, Chirp (a Twitter clone), a blog, and Django REST Framework with Vue |
| `play_html_css_flask/` | HTML and CSS labs, forms, and a Flask to-do list |
| `play_javascript/` | Vanilla JS and Vue: to-do lists, a quotes app over the FavQs API, and Vue talking to Flask |
| `advent_of_code_2020/`, `advent_of_code_2022/`, `2022.py` | Advent of Code (2021 is tucked inside the 2022 folder) |
| `APIs/` | A Readwise API script |
| `random_misc/` | Everything else: a tabata timer, prime numbers, phonemes, a calligraphy helper... |

The history goes back to January 2021, when all of this lived in `johnfial/johnfial`.
